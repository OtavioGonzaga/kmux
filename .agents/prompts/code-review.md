Perform a thorough code review of the changes made in the current branch or any
uncommitted changes (if currently on branches such as main, staging, or
develop).

Focus on:

- correctness
- maintainability
- architecture
- coupling/cohesion
- naming
- error handling
- authorization/security
- performance
- testability
- dead code
- hidden edge cases

Provide actionable feedback ordered by severity. Do not merely point out
problems; also suggest specific improvements, including code examples when
possible. Be clear and direct, avoiding unnecessary jargon. Do not flag changes
that are unnecessary or unrelated to the scope of the review. Be as objective as
possible and do not point out unnecessary changes.
